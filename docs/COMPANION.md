# companion APK 安装与权限指南

companion 是 droid-mcp 的手机伴侣：一个前台服务 + 局域网 HTTP，
**不装 Termux 的手机也能用**（19 个数据类工具，矩阵见 README）。

> 路径各版本会漂移，对不上就去设置里搜关键词，搜不到就提 Issue（写清机型+系统版本），我补。

## 安装（3 步）

1. 去 [Releases](https://github.com/ice-wocker/droid-mcp/releases) 下
   `droid-mcp-companion-<版本>-debug.apk`（debug 签名：全新安装没问题，
   覆盖安装要先卸载旧版）。
2. 安装时 Android 会弹“未知来源”——这是自签名 APK 的正常提示，来源是本仓库的 CI。
3. 打开 App：屏幕上会显示 **IP:端口 + token**（16 位，一机一换），服务是开着的
   （通知栏有常驻通知，杀掉 App 即关服务）。

## 权限（按需给，不给也能用剩下的）

| 能力 | 系统权限 | 不给会怎样 |
|---|---|---|
| 短信收发 | 短信 | `sms_*` 报 `denied`，并告诉你去哪开 |
| 通话记录/拨号 | 通话记录、电话 | 同上；**拨号另有 App 内开关，默认关** |
| 通讯录 | 联系人 | 同上 |
| 通知 | 通知（Android 13+ 首次启动弹窗） | 同上 |
| 定位 | 位置（选“大致位置”就够 network 用） | `location` 报 `denied` |
| 文件 | 全部文件访问（手动去设置开，见下） | storage 只给 Download 和 App 目录 |

App 首次启动会一次性申请，用到哪个给哪个也行，不想给的点拒绝，
对应工具会明确报错而不是静默造假数据。

## 厂商特殊处理

| 厂商 | 后台保活 | 权限入口关键词 |
|---|---|---|
| 小米 MIUI | 任务界面下拉**锁定** + 自启动管理开 | 设置搜“授权管理”→应用权限管理 |
| 华为 EMUI/鸿蒙 | 应用启动管理→改**手动管理**，三个开关全开 | 设置搜“应用管理”→权限 |
| OPPO ColorOS | 自启动开 | 设置搜“应用管理”→权限 |
| vivo OriginOS | 电池→后台耗电管理→允许 | 设置搜“权限管理” |
| 三星 OneUI | 应用程序→电池→**不受限制** | 设置搜“应用程序”→权限 |

后台被杀的症状：Python 端报“连不上 companion”，但手机看着开着——
99% 是这个原因，先锁后台。

## 安全边界（App 介绍页原话，复述一遍）

1. 只监听局域网（端口 4833 写死），不打洞、不上云。
2. 发短信/拨号是真金白银：App 内默认关闭，需手动开开关。
3. 完整 /sdcard 访问要手动开“所有文件访问权限”（设置→应用→特殊应用权限），
   否则 storage 只给 Download 和 App 目录——日常够用。

## 连不上排查

1. 同一 Wi-Fi 吗（手机 5G 和电脑有线不在一个网段最常见）？App 上的 IP 和电脑 ping 一下。
2. token 对吗？重装/清数据会换 token，看屏幕上现在这串。
3. 报 `denied`？是权限问题不是网络问题，看上面表格。
4. 还是不行：Python 端加 `--mock` 先确认 MCP 链路是好的，再回头查网络。
